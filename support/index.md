## Quick help

**The app feels off after I changed my release date.**
Open the Today tab, scroll down to the release footer, and pull to refresh. The plan re-generates automatically. If something looks stuck, force-close the app and reopen.

**I want to start over.**
Settings → Releases → Delete release. Then go to Settings → Set up a new release, or use the "+" button in the release switcher.

**I signed in but I do not see my data on the other device.**
Sign in on the other device with the same Apple ID or Google account. Pull to refresh on the Today tab to trigger a sync. Cross-device sync takes a few seconds.

**A reminder did not fire.**
Open Settings → Notifications and confirm that the master toggle is on, the daily nudge time is set, and your iOS notification permission for Backstage is granted (Settings app → Notifications → Backstage → Allow Notifications).
